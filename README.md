# Solara Quest MVP

Top-down pixel-action prototype for validating combat feel.

## Start

```bash
npm install
npm run dev
```

## Current playable foundation

- Three.js scene with an orthographic top-down camera
- 360-degree WASD movement
- Mouse aiming
- Shift dash with cooldown, movement burst and visible feedback
- Camera smoothing and a pixel-styled test arena

The next implementation phase adds the shared combat state, then the four class kits.
